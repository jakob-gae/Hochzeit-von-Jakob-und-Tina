# Jakob & Tina – Hochzeitswebsite

## Vorschau
`index.html` im Browser öffnen. Für lokale Entwicklung eignet sich Visual Studio Code mit Live Server.

## GitHub Pages
1. Ein GitHub-Repository erstellen (z. B. `hochzeit`).
2. `index.html`, `style.css` und `script.js` ins Hauptverzeichnis hochladen.
3. **Settings → Pages → Deploy from a branch** auswählen.
4. Branch `main` und Ordner `/(root)` wählen und speichern.
